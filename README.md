# 特許は何年？（tokkyo-kikan）

特許・実用新案・意匠・商標の場面を読んで、その期間（30日・2か月・3か月・6か月・1年・1年6か月・3年・10年・20年・25年）を当てる1日5問の学習ゲーム。正解したら、どの法律の決まりか（特許法・商標法・実用新案法と意匠法）も選ぶ。知的財産のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/tokkyo-kikan/>

- 中身は e-Gov 法令検索の特許法（<https://laws.e-gov.go.jp/law/334AC0000000121>）・実用新案法（<https://laws.e-gov.go.jp/law/334AC0000000123>）・意匠法（<https://laws.e-gov.go.jp/law/334AC0000000125>）・商標法（<https://laws.e-gov.go.jp/law/334AC0000000127>）に書いてある期間だけです（2026-11-18 に読みました）。
- 説明は条文を、短く言いかえたものです。出願の書き方・料金の額・審査の中身・期間の延長や救済の細目は省いています。公式の情報の代わりではありません。実際に出願や手続きをするときは、特許庁の案内や弁理士に確かめてください。
- 2段目は、その期間を決めている法律で分けています。
